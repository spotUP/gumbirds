== 3. Meter A, gum tube with half mark (fix layer)
cells: 5 fix cells in one row (1 gum ball icon + 4 tube cells), 40x8 px; fill steps 8 (+ empty); each tube cell holds two 4 px segments, one step each
step -> cells: cell c (0..3 from the left) shows clamp(step - 2c, 0, 2) filled segments: 0 empty tile, 1 half tile, 2 full tile
  step 8 (full): icon normal | 2 2 2 2
  step 7 (in-between): icon normal | 2 2 2 1
  step 6 (3/4): icon normal | 2 2 2 0
  step 5 (in-between): icon normal | 2 2 1 0
  step 4 (half): icon normal | 2 2 0 0
  step 3 (in-between): icon normal | 2 1 0 0
  step 2 (1/4): icon warning | 2 0 0 0
  step 1 (in-between): icon warning | 1 0 0 0
  step 0 (empty): icon warning | 0 0 0 0
half mark: gold bar (slot 15) on the seam between tube cells 2 and 3, 8 px tall (2 px taller than the tube), 3 px caps on rows 0 and 7; it is part of the tiles, always shown; at step 4 the fill ends exactly on it
unique tiles: 13 read back from meter_tiles_1x.png (13 drawn): icon 2 (normal, warning); plain tube cell 5 (empty, half, full, warning half, warning full); cell left of the mark 3; cell right of the mark 3
colours: 11, all from the fix palette 'white' of assets/font/fix_font.json, slots [1, 4, 5, 6, 7, 8, 9, 10, 11, 13, 15]; no second palette (the old draft needed an orange palette for the warning; here the warning uses the red slots 6..8 as tiles)
sprites: 0
