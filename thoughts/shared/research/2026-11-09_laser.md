# Laser visuals

Core logic (fire, heat, lockout 90 frames, +200 per kill, chain) was already right and covered by tests/host/test_core.c. Only addition: Game.kill_x, kill_y, kill_frame (centre and frame of the last kill) for the flash.

## Art reuse
- Beam: hero sheet anim "laser" (24x5, colours #29a5e7 #8cefff #ffffff). Flash: hero sheet anim "hit_flash" (4 frames 13x13). Both already ship in the hero C-ROM set, palette 1, so no new tiles. Laser-only colours (not in hero body, obstacles or city): #29a5e7, #8cefff.
- Hero poses already in the sheet: run_shoot, run_recoil, duck_recoil, jump_recoil.
- Heat bar: new set "heat" (assets/laser/heat_sheet.png/json, drawn by tools/draw_heat_sheet.py, built by tools/build_laser_sprites.py). 16 cells in 8 sprite tiles of 16x8, 12 colours, green to orange to red, hand placed, round-trip 0 mismatches.
- Why sprites, not the fix layer: the fix layer font comes from the nullbios S-ROM we cannot extend, so it cannot draw partial or coloured cells; the label "HEAT" stays on the fix layer.
