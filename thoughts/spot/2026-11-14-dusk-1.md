- **Importer (B2)**: `tools/import_bg_sheet.py` now has a mood table (moon, dusk). Each mood writes
  `assets/<sheet>/<sheet>_sheet.png/.json` with its own tables and defines `BACKDROP_R5/G5/B5` and `TRIP_R5/G5/B5`
  (moon 3,2,7 / 14,10,20; dusk 4,2,8 = #211042 / 11,4,11). The drafts come from

- **Mood (B3)**: `Game.mood` (enum `GAME_MOOD_*`, `GAME_MOOD_COUNT`). `game_next_mood` never repeats the current mood;
  with more than two moods it draws the step from the seeded game rng, so it is written for N moods. `match_start`
  (every round of a match, and the first one) calls it; `game_reset` keeps the mood. Each attract title advances the
  mood (`FlowState.title_mood`). `src/bg.c` keeps both palette sets resident (`DUSK_PAL_SLOT` after the city slots in
  `src/vram_layout.h`), so a mood change reloads no palettes: it writes only backdrop entry 4095, hides all columns with
  one SCB3 run, and rewrites the column strips 8 columns per frame (`BG_MOOD_COLS_PER_FRAME`) inside the normal flush.
  Static asserts hold the dusk layout equal to the moon layout (columns, rows, plane tops, animation ids).
- **Budget (B4)**: `SpriteBudgetMood` carries each mood's own row tables; dusk is built. `sprite_budget_line(m, y, trip)`
  and `sprite_budget_title_line(m, y)` take the mood; the host test asserts worst line <= SB_LIMIT for every built mood.
- **Reach check**: `tests/mame/mood_check.lua`, target `make test-mood`.
