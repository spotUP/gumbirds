## Method

One method for every effect: offline synthesis in Python with numpy only (`tools/make_sfx.py`). No DEViLBOX, no copied or ripped sounds. Voices are a four-operator and a two-operator FM model, SSG-style square waves and noise, layered per effect. Each effect is rendered at 55500 Hz, mastered (saturation, peak limit, short fade), low-passed with a FIR filter and decimated to 18500 Hz mono 16-bit, the ADPCM-A rate. The script asserts length, peak, finite values and the total against 393216 bytes, and it is deterministic.

Run: `/opt/homebrew/bin/python3.14 -I tools/make_sfx.py OUT_DIR [-v] [names]`. A full render takes about one minute. The Makefile runs it for the 42 ROM names, so a clean build needs numpy in that Python and takes about one minute longer.

## Fall sound: root cause and fix

Root cause (most likely, proven on the host, not driven in MAME): a flier that loses its last balloon while it stands on the ground stays `FLIER_ALIVE` and walks. When it walks off an island it drops, but it never enters `FLIER_FALLING`, so the fall event never fired and the first sound was the hazard at the bottom.

Fix: drop detection in `flier_edges`. An alive flier with no balloon, not on the ground, with downward speed at or above `SE_DROP_VY` fires the fall event once per drop. Landing re-arms it. The host test covers: silent below the threshold, once per drop, re-armed on landing, none with a balloon.

Side effect: a jump down to a much lower island without a balloon can also trigger the fall sound.

## Risks and known limits

- Owner listening verdict on the preview page is still open. No effect has been judged by ear.
- The vblank margin stays thin (about 1.4 lines in the stress leg). Any later feature in the logic path can break it.
- `has_parachute` is always 0 today, so the chute cue never fires.
- Flipper and grate cues are for the player only.
- `sound_tick` sends one command per frame (queue of 16). A burst of sounds is delayed by some frames.
- The cue state (`prev_*` fields) is not reset in `se_init`. If the element count changes between stages while playing, one grabber or vent cue can be missed or doubled.
- The first round banner of a run makes no cue, because the start frame is not primed.
- Fall and sizzle key-ons are not proven in MAME, only the fall logic on the host.
- A clean build now needs numpy in `/opt/homebrew/bin/python3.14`.
